# [Nome del Tuo Progetto/Gioco]

## Descrizione
Questo progetto è stato sviluppato per il corso di **E-Health Methods and Applications** (Politecnico di Milano)[cite: 1]. L'obiettivo principale è la progettazione e lo sviluppo di un *serious game* in Unity 3D, incentrato sul tema della **[Health and Digital Literacy / Climate Change]**[cite: 1]. 

Il gioco prende forma a partire dalle specifiche generate da un Large Language Model (LLM), che ha analizzato un set di *User Personas* predefinite per adattare l'esperienza alle caratteristiche, ai bisogni e ai comportamenti degli utenti target[cite: 1].

## Fasi del Progetto

### Fase I: LLM & Personas Analysis[cite: 1]
*   **Input:** Set di *Personas* predefinite (es. Alex Moretti, Sofia Romano, Daniel Conti) che rappresentano diversi archetipi di utenti[cite: 1].
*   **Elaborazione LLM:** Utilizzo di un LLM locale per tradurre le Personas in specifiche di design[cite: 1].
*   **Output generati:** Requisiti di gioco, scenari possibili, situazioni educative, regole comportamentali per i Non-Player Characters (NPC) e relative risposte basate sul contesto[cite: 1].

### Fase II: Game Development[cite: 1]
*   Sviluppo del *serious game* in **Unity 3D** sfruttando le specifiche ottenute nella Fase I[cite: 1].
*   Implementazione della tetrade del game design: *Estetica, Storia, Tecnologia e Meccaniche*[cite: 1].
*   Integrazione di logiche di gamification e personalizzazione per differenti tipologie di giocatori[cite: 1].

## Tecnologie Utilizzate[cite: 1]
*   **Game Engine:** Unity 3D
*   **Linguaggi:** C# (JetBrains Rider / Visual Studio), Python (per la gestione dell'LLM)
*   **Version Control:** Git / GitHub (gestione collaborativa tramite branch, commit e pull request)
